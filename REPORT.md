# Отчёт по заданию «Прототип API с языковой моделью»

## 1. Задача

В проекте `ai-research-automation` реализован модуль разбора аннотаций научных статей. Исследователь задаёт вопрос и передаёт аннотацию одной статьи. Модуль возвращает карточку с целью, методом, результатами и оценкой релевантности. Карточка помогает отобрать статьи для чтения и обзора литературы.

## 2. Реализация

Метод `POST /papers/analyze` принимает JSON с полями `research_question`, `abstract` и `temperature`. FastAPI проверяет запрос и обращается к Qwen3 через OpenAI-совместимый API Ollama. Значение температуры передаётся в запросе к модели. Для извлечения сведений по умолчанию используется `0`.

API передаёт JSON Schema в `response_format` с типом `json_schema`. Ollama ограничивает вывод модели схемой при генерации. Готовую карточку проверяет Pydantic. Сервер сверяет каждую цитату с исходной аннотацией и отклоняет карточку, если точного совпадения нет. Если метод в аннотации не описан, в карточке возвращается `null`.

## 3. Условия проверки

Проверка выполнена 25 ноября 2026 года на Windows с NVIDIA GeForce GTX 1070 (8 ГБ), Python 3.12.14 и Ollama 0.40.18. Использована локальная модель `qwen3:4b-instruct-2507-q4_K_M`.

Оба примера в Swagger UI используют учебные аннотации и вопрос «Помогает ли интервальное повторение запоминать термины?». Первый запрос отправили с `temperature=0`. Перед отправкой запроса без описания метода из готового примера Swagger удалили поле `temperature`, чтобы проверить значение по умолчанию. Первый запрос повторили по три раза при `0` и `0.7` с `seed=42` и `top_p=1.0`.

## 4. Результаты

| Сценарий | HTTP | Результат | Сохранённые данные |
| --- | --- | --- | --- |
| Аннотация с описанием метода | `200` | Указано случайное деление 60 студентов на две группы. Цитата подтверждает результат через неделю | [Запрос](examples/with-method.request.json) · [Ответ](examples/with-method.response.json) |
| Аннотация без описания метода | `200` | `method` равен `null`. Вывод об улучшении запоминания сопровождается цитатой | [Запрос](examples/without-method.request.json) · [Ответ](examples/without-method.response.json) |
| Температура вне диапазона (`3`) | `422` | API отклонил запрос при проверке входных данных | |

Все восемь запросов к модели вернули карточки по схеме. Цитаты в ответах дословно совпали с фрагментами соответствующих аннотаций.

| Температура | Успешные повторы | Время трёх запросов, с | Медиана, с |
| --- | --- | --- | --- |
| `0` | 3 из 3 | 3,006 / 2,939 / 2,955 | 2,96 |
| `0.7` | 3 из 3 | 2,890 / 2,896 / 2,887 | 2,89 |

Время измерено от отправки HTTP-запроса до получения полного ответа. Первый вызов включал загрузку модели и занял 6,91 с. Повторы выполнены на загруженной модели. Затраты на вызовы внешнего API составили 0 ₽ при локальном запуске.

Семь автоматических тестов прошли. Они проверяют передачу температуры и схемы модели, значение температуры по умолчанию, поле `method` со значением `null`, валидацию входа, отклонение отсутствующей цитаты, повреждённый или прерванный ответ и ошибки соединения. [Запуск и спецификация API](README.md)

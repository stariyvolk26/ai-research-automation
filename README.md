# ai-research-automation

Учебный проект по автоматизации работы с научными публикациями. Модуль разбора аннотаций принимает исследовательский вопрос и текст аннотации одной статьи. API возвращает карточку с целью, методом, результатами и оценкой релевантности для обзора литературы.

[Отчёт по заданию и результаты проверки](REPORT.md)

## Локальный запуск

Python 3.11+ и Ollama

```powershell
ollama pull qwen3:4b-instruct-2507-q4_K_M
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app
```

На macOS и Linux путь к Python — `.venv/bin/python`.

В Swagger UI откройте `POST /papers/analyze`, нажмите **Try it out** и выберите пример с описанием метода или без него. [Swagger UI](http://127.0.0.1:8000/docs) · [Спецификация OpenAPI](http://127.0.0.1:8000/openapi.json)

Настройки можно задать в переменных окружения или скопировать `.env.example` в `.env`. Модель Ollama по умолчанию занимает около 2,5 ГБ. [Карточка модели](https://ollama.com/library/qwen3:4b-instruct-2507-q4_K_M)

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `LLM_BASE_URL` | `http://127.0.0.1:11434/v1` | Базовый адрес OpenAI-совместимого API |
| `LLM_MODEL` | `qwen3:4b-instruct-2507-q4_K_M` | Идентификатор установленной модели |
| `LLM_API_KEY` | пусто | Ключ доступа, если его требует провайдер |
| `LLM_TIMEOUT_SECONDS` | `120` | Время ожидания ответа модели в секундах |
| `LLM_SEED` | `42` | Начальное значение для сэмплирования |
| `LLM_TOP_P` | `1.0` | Порог накопленной вероятности кандидатов, число в интервале `(0, 1]` |

При смене провайдера укажите адрес OpenAI-совместимого API и модель с поддержкой `response_format` типа `json_schema` на `POST /chat/completions`. [Совместимость Ollama с OpenAI API](https://docs.ollama.com/api/openai-compatibility)

## `POST /papers/analyze`

Тело запроса передаётся с `Content-Type: application/json`.

| Поле запроса | Тип и ограничения |
| --- | --- |
| `research_question` | Обязательная строка длиной от 1 до 500 символов с непробельным текстом |
| `abstract` | Обязательная строка длиной от 1 до 5 000 символов с непробельным текстом |
| `temperature` | Число от `0` до `2` включительно. Можно опустить, тогда используется `0` |

| Поле ответа `200` | Тип и смысл |
| --- | --- |
| `objective` | Строка с целью работы или `null`, если цель отсутствует в аннотации |
| `method` | Строка с методом или `null`, если метод отсутствует в аннотации |
| `findings` | Массив из 0–3 объектов. В каждом объекте `summary` — краткий результат, `quote` — дословный фрагмент аннотации |
| `relevance` | `high` при прямой связи с вопросом, `medium` при частичной, `low` при слабой связи или её отсутствии |

Все четыре поля присутствуют в ответе. Цель, метод и описание результата модель формулирует на языке вопроса. Цитаты остаются на языке аннотации.

| HTTP | Код ошибки | Причина |
| --- | --- | --- |
| `400` | строка `detail` | Тело запроса не удалось прочитать, например из-за неверной кодировки |
| `422` | поля `detail[].loc`, `detail[].msg`, `detail[].type` | Ошибка входного JSON или ограничений полей |
| `502` | `llm_http_error` | Провайдер отклонил запрос, например из-за имени модели или ключа |
| `502` | `invalid_llm_response` | Генерация прервалась, модель отказала или ответ не прошёл проверку схемы |
| `502` | `unverified_quote` | В аннотации отсутствует точное совпадение с цитатой |
| `503` | `llm_unavailable` | Сервер модели недоступен |
| `504` | `llm_timeout` | Истекло время ожидания модели |

Для `502`, `503` и `504` формат ошибки `{"detail":{"code":"…","message":"…"}}`.

## Пример запроса и ответа

```powershell
$paper = @{
    research_question = 'Помогает ли интервальное повторение запоминать термины?'
    abstract = 'Цель исследования — оценить влияние интервального повторения на запоминание терминов. В эксперименте 60 студентов случайным образом разделили на две группы: интервального и обычного повторения. Через неделю группа интервального повторения вспомнила больше терминов.'
    temperature = 0
} | ConvertTo-Json

Invoke-RestMethod -Method Post -Uri 'http://127.0.0.1:8000/papers/analyze' `
    -ContentType 'application/json; charset=utf-8' -Body $paper | ConvertTo-Json -Depth 5
```

Ответ Qwen3 при контрольном запуске.

```json
{
  "objective": "Оценить влияние интервального повторения на запоминание терминов.",
  "method": "Случайное деление 60 студентов на две группы: интервального и обычного повторения.",
  "findings": [
    {
      "summary": "Через неделю группа интервального повторения вспомнила больше терминов.",
      "quote": "Через неделю группа интервального повторения вспомнила больше терминов."
    }
  ],
  "relevance": "high"
}
```
